- **IDT Limit (Bits 0–15):** A 16-bit value that specifies the size/length of the IDT in bytes (defining the table boundary).
    
- **IDT Base Address (Bits 16–47):** A 32-bit linear base address pointing to the start of the IDT in memory.

## The IDTR is the **hardware pointer** inside the CPU
