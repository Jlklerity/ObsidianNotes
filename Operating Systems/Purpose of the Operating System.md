
### It is the intermediary between the user and hardware

> [!question] Why have an Operating System?
> Its general purpose is to make the user experience easy and usable as it helps the user with underlying tasks that would be tedious if it wasn't for the Operating System talking to the hardware. 
> 
> It also helps the user with allocating resources, memory management and maintaining protection and security
