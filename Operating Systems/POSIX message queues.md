


## Allows for passing messages between processes


### mq_open() - creates a new POSIX message queue or opens an existing queue, returns a message queue descriptor for use by other message queue functions

### mq_close() - closes a message queue

### mq_unlink() -  is used to unlink the message queue

### mq_send() - sends a message to a message queue

### mq_receive() - removes the oldest message with the highest priority from the message queue
