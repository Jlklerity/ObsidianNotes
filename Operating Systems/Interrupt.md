
## An occurrence from either hardware or software telling the CPU to stop whatever its doing and execute a task that has appeared


### Hardware can trigger an interrupt at anytime by sending a signal to the CPU via the system bus


### When the CPU is interrupted, it stops what it is doing and immediately transfers execution to a fixed location

> [!question] Fixed location?
> It usually contains the starting address of the Service Routine of the interrupt is located

## The Interrupt Service Routine executes. When completed the CPU resumes the interrupted computation.
