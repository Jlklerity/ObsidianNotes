
#### Used to tell the compiler to interpret data with a specified datatype forcefully

> [!summary]
> Primarily used for low-level systems programming where you need to bypass the language's standard type system.
> 
> Should never be used when trying to port over products.
> 
> Commonly due to difference in Structural Padding & Packing in different systems 
> (eg. endianness, pointer size, and alignment requirements)
>
